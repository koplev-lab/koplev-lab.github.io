# Koplev Lab website

Public website of the Koplev Lab (KTH Royal Institute of Technology · SciLifeLab). A static site
built with [Astro](https://astro.build); no server, database or third-party scripts.

## Getting started

Requires Node (version in `.nvmrc`).

```sh
npm ci
npm run dev       # http://localhost:4321
npm run build     # static site in dist/
npm test          # build under /base-test/ + Playwright tests
```

Set `SITE_URL` and `BASE_PATH` in the shell when building for a sub-path, e.g.
`SITE_URL=https://example.org BASE_PATH=/website npm run build`.

## Where things live

| Path              | Contents                                                           |
| ----------------- | ------------------------------------------------------------------ |
| `src/content/`    | Editable text: site settings, pages, projects, members, highlights |
| `src/data/`       | Publications list (generated by `npm run pubs` from OpenAlex)      |
| `src/assets/`     | Figures, portraits and the logo                                    |
| `src/lib/`        | Data layer: reads the content and hands typed data to the pages    |
| `src/pages/`      | One file per page                                                  |
| `src/layouts/`    | The page shell (header, nav, footer)                               |
| `src/components/` | Shared pieces, including the home page's staining animation        |
| `src/styles/`     | Design tokens, base and print styles                               |
| `tests/`          | Content, link, accessibility and static-output checks              |
| `scripts/`        | Publications fetch, favicons, screenshots, test server             |
| `docs/DESIGN.md`  | The design brief and the decisions behind it                       |

Content marked `placeholder: true` is a draft awaiting approval; `npm run dev` shows it with a
"draft" marker and every build lists it.
